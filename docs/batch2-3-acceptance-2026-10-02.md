## 自动化检查与评估

- `npm run check`：后端 67 项测试、4 项前端辅助函数测试、TypeScript 与生产构建、Ruff、Prettier 均通过。
- 冻结集：`tests/evaluation/monthly-v1.json`，10 道聚合、8 道比较、6 道维度、6 道异常/报告。每题有固定指标、日期、范围和本期/基期数值；比较还核对差额，排名核对门店顺序，异常题核对阈值结果和限制说明。人工可手算的 `metric_data()` 夹具与较大的演示夹具相互补充。
- 30/30 是确定性规则在冻结范围内的结果，不代表开放问题泛化或真实模型评估。拒答集合独立计数，不混入成功率。
- 浏览器完整回归 1/1 通过（约 4.3 秒）：使用真实生产页面和 FastAPI 临时库，通过测试桥接传递实际请求/响应，不依赖监听端口。覆盖登录、空状态、CSV 校验发布、澄清重试、多指标分析、报告审核、任务和报告刷新恢复、建议反馈、修订 URL、未保存修改保留/放弃、筛选下钻、退出及会话过期提示；首次进入和主动退出不误报过期。打印页面生成的五页中文 PDF 已检查文字、表格、跨页表头和反馈记录。它不验证真实网络、反向代理或证书。
- 可复跑：`npm run check`；安装匹配的浏览器后 `npm run test:browser`。本机使用已安装的 Chromium，默认配置支持 `RETAILPILOT_BROWSER_EXECUTABLE` 指定浏览器路径。持续检查配置位于 `.github/workflows/checks.yml`；当前目录没有被识别为 Git 仓库，尚未在托管仓库触发远程 CI。

## 性能测量

每种规模独立临时库，均包含 5 个发布版本、1000 条任务摘要和 1000 条报告摘要。看板冷/热缓存各 50 次，四类列表各 50 次；5 位用户在同一 ASGI 事件循环分别读取 50 次，同时进行一次同规模 CSV 校验导入。失败率为零。

| 每版明细 | 冷看板 P95 | 热看板 P95 | 列表最慢 P95 | 并发用户最慢 P95 | 导入+发布最长 |
| --- | --- | --- | --- | --- | --- |
| 1,000 | 0.006 秒 | 0.0023 秒 | 0.093 秒 | 0.011 秒 | 0.030 秒 |
| 10,000 | 0.027 秒 | 0.0022 秒 | 0.097 秒 | 0.012 秒 | 0.232 秒 |
| 100,000 | 0.296 秒 | 0.0023 秒 | 0.100 秒 | 0.127 秒 | 2.380 秒 |

上述结果满足本次**进程内** P95≤3秒、导入≤60秒的目标；不包含网络上传、TLS、远程机器和真实模型服务延迟。完整环境、响应字节、阶段耗时与原始测量见 [性能记录](benchmark-2026-10-02.json)，脚本为 `scripts/benchmark.py`。

10万条场景测试进程峰值内存约 850 MiB，包含生成夹具、多次请求编码、导入及历史结果；不是服务常驻内存测量。五版数据与历史记录占用较大，不宣称 SQLite 可无限扩展；更大规模应重新测量并安排数据库迁移。
